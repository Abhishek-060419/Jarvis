# 🤖 Jarvis – Personal AI Assistant

A personal AI-powered voice assistant being developed in Python to understand natural-language commands and perform actions on the user's computer.

The project aims to combine speech recognition, intent parsing, AI-based command verification, and action execution into a modular personal assistant.

> **Status:** 🚧 Work in Progress



## 📌 Overview

Jarvis is a personal AI assistant designed to allow users to interact with their computer using natural-language commands instead of rigid predefined commands.
